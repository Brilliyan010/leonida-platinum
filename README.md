Leonida Platinum is an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: a saved checklist with kind and grade filters, a spoiler shield, export and import, per-trophy count trackers, a 5-stage roadmap to the platinum with points of no return, and a cited guide for every trophy — including the one trophy that can be missed. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
