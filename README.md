Leonida Platinum is an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5 — a checklist with saved progress, kind and grade filters, a spoiler shield, export and import, a 5-stage roadmap to the platinum, the one missable trophy flagged, and a cited guide with steps for every trophy. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide runs entirely from its own files, with the network off. To build the submission output instead: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
